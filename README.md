# purrfectorder.com

Website for **Purrfect Order**, a cozy first-person game about putting every cat to bed.

Plain static HTML, served with GitHub Pages at https://purrfectorder.com.

- `index.html` – the whole page (styles and the small newsletter script are inline)
- `assets/` – screenshots
- `fonts/` – self-hosted web fonts (SIL Open Font License, see `fonts/LICENSE-*.txt`)
- `CNAME` – custom domain for GitHub Pages

Placeholders still to fill in before launch: imprint (Impressum), full privacy policy, Steam store link, newsletter service, community links.
